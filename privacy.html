Privacy Policy

Bounce Arena Uploader · last updated October 18, 2026

What this app is

The Bounce Arena Uploader is a private tool used only by the owner of the Bounce Arena YouTube channel. It is not offered to the public.

What it accesses

When the channel owner signs in with Google, the app uses the YouTube Data API and YouTube Analytics API to:

  • upload videos and thumbnails to the owner's own channel and schedule when they go public, and
  • read that channel's own statistics (such as views and subscribers) to decide which videos to make next.

What it does not do

  • It does not collect, store or process information about anyone other than the channel owner.
  • It does not sell, share or transfer any data to third parties.
  • It does not use Google user data for advertising.

Storage

The sign-in token is stored only on the channel owner's own computer and is used only to perform the actions above. Access can be removed at any time from the Google Account's security settings (myaccount.google.com/permissions).

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
